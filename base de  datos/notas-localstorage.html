Cómo funciona
Esta página intenta conectarse a http://localhost:3000/api/notes. Si el servidor (server.js, incluido junto a este archivo) está corriendo, cada nota se guarda en una base de datos SQLite real y localStorage actúa solo como caché local para carga instantánea. Si el servidor no responde, la app sigue funcionando en modo local, guardando únicamente en localStorage. Ejecuta npm install && npm start en la carpeta del servidor para activar el modo con base de datos.
